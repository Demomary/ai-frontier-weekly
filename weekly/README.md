# 每周报告

按 ISO 周编号归档，文件名格式：`YYYY-Www.md`。原则上每周一整理上一完整自然周（周一至周日）的重要进展。

## 报告模板

每期建议包含：
1. 本周最重要进展（按重要性排序）
2. 基础模型与模型研发
3. Agent 与 Harness
4. 具身智能
5. AI 眼镜与第一视角智能设备
6. 现实世界交互
7. 工业 AI 与自动化
8. AI 硬件与基础设施
9. 前沿研究与开源生态
10. 对 C/C++、Linux、DPDK、协议仿真、PLC 和工业自动化的影响
11. 趋势判断、待验证问题与下周观察点

每条新闻注明事件日期、发布日期、实质变化、来源链接和证据性质。
