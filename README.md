# AI Frontier Weekly

AI 技术与产业周报与长期专题知识库。持续追踪模型、Agent、具身智能、AI 眼镜、现实世界交互、工业 AI、AI 硬件和开源研究。

## 编辑原则
- 每周归档上一周的重要进展。
- 优先使用官方公告、论文、代码仓库、独立评测和可靠媒体来源。
- 区分厂商宣传、实验室演示、独立验证、产品发布与真实商业部署。
- 记录原始发布日期、来源链接和证据性质；不编造、不重复包装旧消息。
- 特别分析对 C/C++、Linux、DPDK、通信协议仿真、PLC 与工业自动化的影响。

## 目录
- `weekly/`：每周报告
- `topics/`：长期专题追踪
- `companies/`：重点公司动态
- `research/`：论文、基准测试与开源项目
